# Health Dashboard 演示（V2.1 + 专业肌肉恢复图）

这是健康工作室 Dashboard 的公开演示版本。根目录为 V2.1（分页导航、肌群恢复图、训练覆盖、饮食与营养、Apple Health 补录演示、今日提示）；`v2.1/` 保留上一版 V2.1，`v2/` 保留 V2 视觉改版，`v1/` 保留 V1，用于对照与回退。

页面中的全部数值和记录均为虚构模拟数据，仅用于界面预览。肌群恢复状态为规则模型估算，不是医学检测结果。

本仓库不包含真实健康资料、个人身份信息、访问凭证、环境变量或后端接口，也不连接任何数据库或 Apple Health。

人体肌肉图形来自 [Open-Muscle-Map](https://github.com/PerspicaciousGuy/Open-Muscle-Map)（MIT），许可证与改动说明见 `src/assets/body/LICENSE`、`src/assets/body/ATTRIBUTION.md`。
